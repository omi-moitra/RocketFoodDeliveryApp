# Module 14 screen reference

This public reference describes the original wireframe without its embedded personal contact details.

- Account selection: Customer and Courier choices, with a shared header and logout.
- Restaurants: rating and price filters, restaurant cards, and bottom navigation.
- Order confirmation: item quantities and totals, optional email/SMS checkboxes, and confirmation action.
- Account: read-only primary email, editable role email and phone, and an update action. Use `customer@example.com` and `+1-202-555-0100` for fictional examples.
- Courier deliveries: order ID, address, status, and details action; details include order items and the next delivery action.

The original image-based PDF is retained only in the private recovery archive. The existing application and feature specifications provide the detailed visual contract.
